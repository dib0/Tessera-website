# Tessera-website

The website for the [Tessera Language](https://github.com/dib0/Tessera-language), built with the Tessera Language itself as a proof of concept.

## About Tessera

Tessera is a compact, safety-first programming language designed for LLM-assisted software development. Its source is plain text, its syntax is intended to be compact and regular, and design rationale is kept alongside the code.

The language is in an early design and proof-of-concept stage. Its syntax and compiler are not yet stable, so examples on the website are proposals, not a released language. See the [language repository](https://github.com/dib0/Tessera-language) for the design goals, syntax sketch, and bootstrap plan.

## Purpose of this repository

This repository holds the source for the Tessera website. It serves two goals:

- Inform visitors about the Tessera Language.
- Demonstrate the language by building the site in Tessera.

## Status

Early work in progress. Features and content may change as the language develops.
